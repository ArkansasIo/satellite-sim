# Data Collection Console

The ground UI exposes a dedicated Data Collection workspace.

## Live views

- Collection sources and sampling rates
- Packets received per second
- Samples collected per second
- Dropped/invalid packet count
- Data-quality state
- Latest engineering values
- Frequency/channel observations
- Audio/image/video products received
- Onboard storage and downlink queue depth

## Historical views

Operators can select a spacecraft, subsystem, metric, time range and quality state, then inspect or export the collected dataset.

## Provenance

Each sample links back to its spacecraft, subsystem, sequence number, onboard tick, receive timestamp and collection source.

The UI is designed for simulation and ground-station data analysis. It does not operate real RF equipment or real spacecraft.
