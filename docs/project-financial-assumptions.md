# Project Financial Assumptions

This page defines the assumptions behind the commercial planning scenarios. Values are estimates for discussion, not quotes or commitments.

## Cost-model boundaries

- Treat staffing, benefits, recruiting, contractor rates, cloud services, test equipment, travel, legal/accounting, and contingency as separate cost categories.
- Distinguish one-time setup and development costs from recurring operating costs.
- Document currency, pricing date, tax treatment, and whether each estimate includes overhead.
- Use fully loaded annual compensation for employee cost estimates and include ramp-up time for hiring.
- Record external quotes and contract terms separately from planning estimates.

## Scenario estimates

The figures in [Business Planning File Index](business-plan-index.md) are broad planning envelopes. They should be recalculated from a role-by-role staffing plan, schedule, infrastructure forecast, procurement quotes, and explicit contingency percentage before any funding decision.

## Validation checklist

1. Replace assumed compensation and contractor rates with current local data or written quotes.
2. Confirm staffing start dates, hiring lead time, and team ramp-up.
3. Estimate infrastructure and test-equipment costs by month.
4. Separate capital expenditures from recurring expenses where applicable.
5. Include taxes, insurance, legal, compliance, and contingency where relevant.
6. Record the source, date, owner, and confidence level for each assumption.

## Disclaimer

This is a planning template, not financial, accounting, tax, or investment advice. Verify all figures independently before making financial commitments.
