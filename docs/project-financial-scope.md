# Project Financial Scope

## Currency

All planning numbers are in CAD.

## Included

These estimates cover software engineering and prototype engineering for the satellite-sim program.

Included:
- C++ simulation
- spacecraft and ground-station software
- telemetry and command systems
- databases
- web/desktop UI
- authentication and security engineering
- Arduino and ATmega328P prototypes
- CI/CD and automated testing
- documentation
- prototype hardware and development infrastructure

## Excluded

The estimates do not include:
- spacecraft launch services
- flight-qualified spacecraft hardware
- launch vehicle costs
- environmental qualification
- real DSN service contracts
- RF spectrum licensing
- regulatory approval
- production satellite manufacturing
- operational mission staffing after product release

Those items require separate budgets.

## Investment strategy

Use staged investment:

1. MVP planning envelope: approximately $1.8M–$3.1M.
2. Validate technical and commercial assumptions.
3. Expand toward the commercial program only after measurable MVP milestones.
4. Target approximately $6M–$10M for the larger commercial development program.

These figures are planning estimates, not quotes or commitments.
