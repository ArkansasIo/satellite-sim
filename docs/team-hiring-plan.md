# Team Hiring Plan

## Stage 1 — Build the core

Hire:
- 1 technical lead
- 1 C++ engineer
- 1 backend/database engineer
- 1 frontend engineer
- 1 embedded engineer

Team size: **5**

Goal: prove the architecture and end-to-end simulator.

## Stage 2 — Add delivery capacity

Add:
- 1 QA/DevOps engineer
- 1 additional C++ or embedded engineer

Team size: **6–7**

Goal: parallelize implementation and establish reliable CI and hardware testing.

## Stage 3 — Commercial expansion

Add:
- security
- second embedded engineer
- second backend engineer
- second frontend engineer
- telemetry/data engineer
- aerospace/mission specialist
- second QA engineer
- DevOps/cloud
- product/project manager
- technical writer

Nominal team size: **17**

## Stage 4 — Scale selectively

Grow toward 20 only when metrics justify it:
- backlog growth
- customer support load
- test duration
- deployment frequency
- telemetry/data volume
- hardware integration workload

Avoid hiring ahead of validated demand.
