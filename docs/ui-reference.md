# UI Reference

## Ground station

The ground station provides fleet-wide views and remote control. Its primary navigation is Mission Control, Satellites, Telemetry, Commands, Memory/Storage, Communications, Display, Tools, and Settings.

## Spacecraft terminal

The local spacecraft terminal provides a DOS/CMD-style command prompt backed by the virtual assembly environment.

## CRT mode

CRT mode provides 4:3 presentation, scanline simulation, phosphor persistence, overscan, brightness/contrast controls, horizontal/vertical hold, and blue or black monochrome presentation.

## Modern TV mode

Modern mode provides selectable resolution, refresh rate, HDR, VRR, low-latency mode, HDMI/DisplayPort-style inputs, captions, and accessibility controls.

The display layer is an interface simulation and is not tied to a particular commercial television.
